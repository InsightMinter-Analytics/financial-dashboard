# Financial Dashboard (Synthetic Data)

This project creates a real-time financial dashboard using Streamlit and synthetic data.

---

## 🚀 How to Run

1. Clone the repo:
   ```bash
   git clone https://github.com/your-username/financial-dashboard.git
   cd financial-dashboard

2. Install dependencies:
   pip install -r requirements.txt

3. Run Streamlit:
   streamlit run dashboard.py

## 🌐 Deployment

1. Push this repo to GitHub.

2. Connect it to Streamlit Cloud.

3. Select dashboard.py as the entry point.

Your dashboard will be live with a public URL.

---

✅ With this setup, you just fork → push → deploy. Streamlit Cloud will automatically build and host your dashboard.
